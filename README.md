# 返すか、待つか

住宅ローンの繰り上げ返済シミュレーターです。

住宅ローン控除を計算に入れて、「今すぐ繰り上げ返済したほうが得か、
控除が終わるまで待ったほうが得か」を判定します。

- 無料・登録不要
- 入力した数字はブラウザの中だけで計算されます。どこにも送信されません

→ https://jutaku-loan-2000.github.io/tool/

YouTube「主婦、住宅ローン2000万をYouTubeで返します」で使っているツールです。

---

私は税理士でもファイナンシャルプランナーでもありません。
実際に繰り上げ返済をする前に、ご自分の銀行や税務署に確認してください。
